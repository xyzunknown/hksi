# HKSI 学习助手 Android 版

这是一个供个人备考使用的离线 APK，无需登录或付费。

## 安装

1. 把 `HKSI-Study-1.0.apk` 发送到安卓手机。
2. 在手机上点开安装包。
3. 如果系统拦截，允许当前文件管理器“安装未知应用”，然后继续安装。

支持 Android 8.0 及以上版本。

## 已包含

- 9 个章节、1283 道练习题、113 张记忆卡。
- 章节阅读、笔记、收藏、错题、专项练习和 60 题模拟考试。
- 学习数据保存在手机本地，关闭或重启应用后仍会保留。
- 可在“我的 → AI 设置”里直接填写自己的 OpenAI Key。请不要把 Key 发到聊天或写进共享文件。
- 可在“我的 → 多设备同步”里填写现有网页同步地址和同步码。

## 同步说明

同步不需要账号，但需要先把项目原有的网页同步服务部署好，然后在应用里填写以 `/api/sync` 结尾的 HTTPS 地址。没有填写时，应用保持纯本机模式，不影响离线学习。
